# Volant Video Assets

You can drop your custom video file directly into this folder:

- File name: `volant-demo.mp4`
- Path: `public/videos/volant-demo.mp4`

The home page video player will automatically check for and play this local video before falling back to remote CDN sources or the drone poster fallback image.

Recommended video specifications:
- Format: MP4 (H.264 / AAC) or WebM (VP9)
- Resolution: 1080p (1920x1080) or 720p (1280x720)
- Aspect Ratio: 16:9
- Optimized for web streaming (faststart / moov atom at beginning)
